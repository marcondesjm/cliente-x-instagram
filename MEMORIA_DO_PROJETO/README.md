# Memoria do Projeto

Esta pasta guarda uma memoria simples e portavel do projeto `cliente-x-instagram-modern`.

Use estes arquivos para salvar o ponto atual, recuperar decisoes importantes e continuar o trabalho sem depender apenas do historico do chat.

## Arquivos

- `STATUS_ATUAL.md`: resumo do estado mais recente confirmado.
- `HISTORICO.md`: linha do tempo das atualizacoes importantes.
- `COMO_ATUALIZAR.md`: regra para manter esta memoria organizada.

## Regra de uso

Quando quiser congelar um ponto do trabalho, diga:

`atualiza a memoria do projeto`

Eu devo registrar:

- data e hora;
- branch e commit atual;
- o que foi alterado;
- o que foi validado;
- o que ainda falta;
- se houve ou nao deploy/publicacao.
